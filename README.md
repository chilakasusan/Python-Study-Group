## 🎯 Case Study Overview
`AgriClimate Solutions Ltd.` needed a simplified program to help farmers
understand how daily weather conditions may affect crop production —
without any AI, APIs, or databases, using only the fundamentals covered
in Lessons 1–5.

The system:
- Models a daily weather observation for a farm (temperature, rainfall,
  humidity, wind speed, irrigation availability)
- Calculates rainfall difference and temperature margin against safe thresholds
- Updates rainfall using an assignment operator
- Evaluates whether growing conditions are favorable using logical operators
- Determines whether farmer action is required
- Generates a formatted Weather Impact Analysis Report
- **Bonus:** runs the same analysis on a second farm (Benue) and compares
  both farms to identify which needs more urgent attention

**Constraint:** the entire solution uses only variables, data types,
arithmetic/assignment/comparison/logical operators, and string formatting —
no if-statements, loops, functions, lists, dictionaries, or external
libraries, by design, to build a solid foundation before decision-making
logic is introduced in later lessons.
