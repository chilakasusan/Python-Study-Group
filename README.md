# Weather Impact Analysis System

Python Study Group — Case Study Project #12
AgriClimate Solutions Ltd. | Coach Timothy | #PythonStudyGroup #StudyGroup #CaseStudy

## Overview
A simplified weather impact analysis tool that helps determine whether farming
conditions are favorable and whether farmer action is required, built using
only Python fundamentals: variables, data types, arithmetic operators,
assignment operators, comparison operators, and logical operators.

No if-statements, loops, functions, lists, dictionaries, or external libraries
were used — by design, to reinforce core fundamentals before moving on to
decision-making logic.

## What it does
- Models a daily weather observation for a farm (temperature, rainfall,
  humidity, wind speed, irrigation availability)
- Calculates rainfall difference and temperature margin against safe thresholds
- Updates rainfall using an assignment operator
- Evaluates whether growing conditions are favorable using logical operators
- Determines whether farmer action is required
- Generates a formatted Weather Impact Analysis Report
- **Bonus:** runs the same analysis on a second farm (Benue) and compares
  both farms to identify which needs more urgent attention


## Concepts applied
Variables · Data Types · Arithmetic Operators · Assignment Operators ·
Comparison Operators · Logical Operators
